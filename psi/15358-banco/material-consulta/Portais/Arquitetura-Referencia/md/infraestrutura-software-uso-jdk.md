# Uso do JDK (JAVA Development KIT)

## Objetivo

Apresentar as informações referentes a arquitetura de referência para uso e instalação do JAVA JDK no ambiente centralizado e descentralizado da CAIXA.

## Histórico

Em 2019 a Oracle passou a oferecer suporte estendido pago (Oracle Java SE Subscription) às versões mais estáveis (LTS) para usuários do JAVA SE.

O Java SE tem em seu pacote de instalação, entre outros, os softwares:

- The Java Development Kit (JDK) -- para ambiente para desenvolvimento

- Java Runtime Environment (JRE) -- para ambiente de execução

Desta forma, as versões LTS que devem ter contrato de suporte ativo com a Oracle são:

- Java JDK Oracle - Versão 8 a partir da release 211

- Java JDK Oracle - Versão 11 -- todas as releases

- Java JDK Oracle - Versão 17 -- todas as releases

- Java JDK Oracle - Versão 21 – todas as releases

A Oracle mantém ainda o OpenJDK sob licenciamento GPL, que tem suas atualizações semelhantes ao JDK com releases sendo distribuídas sistematicamente e apoio da comunidade Oracle de desenvolvedores.

Desta forma, para a CAIXA se adequar quanto à equalização de versões e fornecedores, bem como ao regime de licenciamento Oracle, disponibilizamos abaixo arquitetura de referência que deverá ser seguida em todos os ambientes CAIXA.

## Principais Recomendações de Uso

Na CAIXA deve-se utilizar preferencialmente o OpenJDK nas versões compatíveis com o Jboss em uso, conforme matriz de compatibilidade, que pode ser pesquisada aqui: [Customer Portal Search (redhat.com)](https://access.redhat.com/search/knowledgebase?q=+Supported+Configurations&p=1&rows=10)

Nas máquinas de uso de escritório de não desenvolvedores, deve-se remover todo e qualquer pacote completo JAVA Oracle, que tenha também o Java JDK, mantendo apenas instalado o JRE (Java Runtime Environment), suficiente para uso dos sistemas desenvolvidos na linguagem Java.

## Demais considerações

1. Sistemas e ambientes que não apresentarem compatibilidade imediata com o OpenJDK devem ter contrato de suporte com a Oracle ativo.

## Glossário

1. Linguagem JAVA -> Java é uma linguagem de programação e plataforma de computação liberada pela primeira vez pela Sun Microsystems em 1995. Ela evoluiu para uma grande participação no mundo digital dos dias atuais, oferecendo a plataforma confiável na qual muitos serviços e aplicativos são desenvolvidos. Produtos e serviços novos e inovadores projetados para o futuro continuam a confiar no Java também. ¹

2. JDK -- Java Development Kit -> É um pacote disponibilizado pela Oracle com todo ambiente necessário para criação e execução dos aplicativos Java. É composto pelo compilador e pelas bibliotecas (API's) necessárias para criação de programas em Java e ferramentas úteis para o desenvolvimento e para testes dos programas escritos nessa linguagem. ²

3. JRE -- Java Environment Kit -> Esse kit é composto pela Java Virtual Machine (JVM), nas classes centrais e pelas bibliotecas de suporte da plataforma Java. É o componente necessário para executar o software Java. ³

4. OpenJDK -> É uma implementação livre e gratuita da plataforma Java, Edição Standard (\"Java SE\"), licenciada pela GNU GPL versão 2. É o resultado dos esforços da Comunidade Java para a evolução atemporal da linguagem. ^4^
