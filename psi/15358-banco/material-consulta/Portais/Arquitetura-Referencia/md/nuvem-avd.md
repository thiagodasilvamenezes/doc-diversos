# Azure Virtual Desktop (AVD)

**Importante:** Essa arquitetura de referência se encontra em fase de validação e não possui nenhum indicativo de uso geral pelas equipes. Havendo entendimento que ela se encaixa nas necessidades de seu sistema, a SUART deve ser acionada.

1. Azure Virtual Desktop (AVD) é a solução de VDI da Microsoft disponível via portal do Azure.

2. O AVD possibilita acesso a área de trabalho virtual de forma multissessão (vários usuários simultâneos) utilizando as licenças de Windows e Office já contratadas para os usuários da CAIXA.

## Perfis de usuário

1. Perfil Escritório Máquinas com perfil de "usuário padrão"; para acesso a internet, softwares básicos e acessos aos sistemas on premises. Esse é o perfil adequado para todos os empregados não enquadrados no "Perfil Fábrica".

2. Perfil Fábrica Máquinas com perfil de "usuário avançado"; para o desenvolvimento de sistemas, codificação, testes, etl, utilização de programas que demandam maior poder de processamento e/ou armazenamento massivo de dados.

## Configuração padrão

1. Perfil Escritório 4 vCPU 16 GB RAM 6 usuários por vCPU

2. Perfil Fábrica 4 vCPU 16 GB RAM Multisessão até 4 usuários por VCPU (atualmente 1 usuário por VCPU)

## Componentes da arquitetura

1. Gateway subnet Um gateway de VPN é um tipo de gateway de rede virtual que envia o tráfego criptografado entre sua rede virtual e seu local em uma conexão pública. Também pode ser utilizado para realizar o tráfego entre redes virtuais no backbone do Azure.

2. Vnet -- AVD -- Piloto A Vnet é semelhante a uma rede tradicional que você operaria em seu próprio data center, mas traz benefícios adicionais da infraestrutura do Azure, como escala, disponibilidade e isolamento

3. On-premises network É a rede segura referente à estrutura on premises.

4. Azure Active Directory Solução da azure para o gerenciamento de identidade com segurança integrada. O Azure AD fornece logon único, autenticação multifator (MFA) e acesso condicional.

5. Azure AD Connect O Azure AD Connect é um aplicativo da Microsoft local projetado para atender e atingir suas metas de identidade híbrida.

6. Windows Virtual Desktop O serviço Web Access dentro do Windows Virtual Desktop permite que o usuário acesse desktops virtuais e aplicativos remotos por meio de um navegador da Web compatível com HTML5, como faria com um PC local, de qualquer lugar em qualquer dispositivo.

7. Storage account Uma conta de armazenamento do Azure contém todos os seus objetos de dados do Armazenamento do Azure, incluindo blobs, compartilhamentos de arquivos, filas, tabelas e discos. A conta de armazenamento fornece um namespace exclusivo para seus dados de armazenamento do Azure que podem ser acessados ​​de qualquer lugar por HTTP ou HTTPS. Os dados em sua conta de armazenamento são duráveis ​​e altamente disponíveis, seguros e escaláveis.

8. AD DS Server Um diretório é uma estrutura hierárquica que armazena informações sobre objetos na rede. Um serviço de diretório, como Active Directory Domain Services (AD DS), fornece os métodos para armazenar dados de diretório e disponibilizar esses dados para usuários e administradores de rede. Por exemplo, AD DS armazena informações sobre contas de usuário, como nomes, senhas, números de telefone e assim por diante, e permite que outros usuários autorizados na mesma rede acessem essas informações.

9. VNET peering O emparelhamento de rede virtual (peering) permite que você conecte facilmente duas ou mais redes virtuais no Azure. As redes virtuais aparecem como uma só para fins de conectividade. O tráfego entre máquinas virtuais em redes virtuais com peering usa a infraestrutura de backbone da Microsoft. Assim como o tráfego entre máquinas virtuais na mesma rede, o tráfego é roteado apenas pela rede privada da Microsoft.

10. HUB-SEC É um serviço de gerenciamento de procedimentos de segurança na nuvem que realiza verificações de práticas recomendadas de segurança, agrega alertas e permite a correção automatizada.

11. ExpressRoute É a solução da Azure de conexão de fibra dedicada para a rede privada entre os datacenter da Azure e a infraestrutura on premises. O ExpressRoute oferece uma conexão rápida e confiável com largura de banda de até 100 Gbps, o que propicia um cenário favorável para migração de dados, replicação para continuidade de negócios, recuperação de desastre e outras estratégias de alta disponibilidade.
