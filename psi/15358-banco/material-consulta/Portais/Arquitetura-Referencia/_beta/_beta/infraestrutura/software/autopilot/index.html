    MICROSOFT WINDOWS AUTOPILOT

    Arquitetura de Solução

    Atualmente o principal ponto para endereçar uma recuperação mais ágil da imagem sem utilização de pendrive seria termos uma partição de recuperação na nossa imagem ou a utilização da imagem padrão de cada fabricante do hardware que já possui a partição e usar o Microsoft Autopilot para finalizar o provisionamento da estação.

    Esse documento visa apresentar uma arquitetura de referência para a implantação do Microsoft Windows Autopilot, com o objetivo de auxiliar a empresa a automatizar e simplificar o provisionamento, a configuração e a entrega de dispositivos Windows 11 para seus usuários finais.

    O Windows Autopilot permite a preparação de dispositivos para uso corporativo com configurações padronizadas, políticas de segurança e aplicações necessárias, garantindo uma experiência de configuração simplificada para os usuários finais.

    Identificação - Benefícios

    Implantação Simplificada: O Autopilot permite que novos dispositivos sejam configurados diretamente da nuvem, sem a necessidade de intervenção manual complexa. Isso significa que os dispositivos podem ser entregues prontos para uso, com todas as configurações e aplicativos pré-instalados.

    Consistência nas Configurações: Todos os dispositivos seguem um padrão definido pela organização, o que ajuda a evitar erros de configuração e garante uma experiência uniforme para os usuários.

    Economia de Tempo: A equipe de TI economiza tempo ao não precisar preparar manualmente cada dispositivo. Isso permite que os profissionais de TI foquem em tarefas mais estratégicas, aumentando a eficiência.

    Experiência do Usuário Melhorada: Os usuários recebem seus dispositivos prontos para uso corporativo após uma rápida autenticação, sem precisar passar por um processo de configuração complexo.

    Facilidade de Gerenciamento: O Autopilot facilita a gestão contínua dos dispositivos, permitindo atualizações de software, aplicação de políticas e gerenciamento de dispositivos móveis de forma eficiente.

    Compatibilidade com Dispositivos Existentes: O Autopilot também pode ser usado para reconfigurar dispositivos existentes, facilitando a migração para novas versões do Windows ou a reposição de dispositivos.

    Eficiência Operacional: Elimina a necessidade de imagens tradicionais e provisionamento manual.

    Segurança: Configurações e políticas aplicadas desde o primeiro uso.

    Objetivo

    Automatizar o provisionamento de dispositivos e reduzir a necessidade de intervenção manual no processo de configuração de novos dispositivos.

    Padronizar a configuração de dispositivos e assegurar que todos os dispositivos sigam as mesmas configurações e políticas de segurança.

    Melhorar a experiência do usuário final e proporcionar uma experiência de configuração simples e direta para os funcionários.

    Simplificar o gerenciamento de dispositivos através da integração com ferramentas de gerenciamento baseadas na nuvem e garantir uma experiência consistente para os usuários finais.

    Tecnologia - Requisitos

    Azure Active Directory (Azure AD):

    • Todos os dispositivos devem estar registrados no Azure AD.

    • Usado para autenticação e registro dos dispositivos no domínio da organização.

    • Permite diferentes opções de ingresso, como Azure AD Join ou Hybrid Azure AD Join.

    Microsoft Endpoint Manager (Intune):

    • Utilizado para gerenciar dispositivos, aplicativos e políticas de conformidade.

    • Usado para criar perfis de configuração para definir políticas de segurança, configurações de rede e outras políticas corporativas.

    • Gerenciamento de Aplicativos com implantação e atualização de aplicativos corporativos de forma centralizada.

    • Usado para monitorar e gerar relatórios sobre o estado de conformidade dos dispositivos.

    • Licenciamento - Licenças apropriadas do Microsoft 365 ou Enterprise Mobility + Security (EMS).

    Windows Autopilot:

    • Conjunto de tecnologias para automatizar a implantação de dispositivos Windows.

    • Requer dispositivos registrados no Microsoft Endpoint Manager (MEM) ou Intune.

    • Usado para criar perfis do Autopilot e para definir como os dispositivos devem ser configurados automaticamente.

    • Suporte a vários cenários de implantação, incluindo novas aquisições, reatribuição de dispositivos e redefinição de dispositivos existentes.

    Arquitetura implantada (ATUAL)

    Atualmente a CAIXA usa uma imagem própria personalizada, sem uma partição de recuperação e aplicada nos dispositivos via uso de pendrive.

    No ambiente CORPCAIXA, atualmente trabalhando em modo de co gerenciamento junto ao Intune, que é um serviço de gerenciamento de endpoint unificado baseado em nuvem da Microsoft para dispositivos corporativos e BYOD. Via SCCM/Intune são distribuídas diversas políticas de configurações dos endpoints para a padronização do ambiente além de distribuições de softwares necessários para o dia a dia dos usuários, o SCCM (System Center Configuration Manager) também é responsável por toda a coleta de inventário das estações, painéis de BI consomem estes dados para gerar indicadores de conformidades da estação. Para máquinas que estão em home office possuímos ainda um server CMG que é um gateway no AZURE que redireciona os reports da máquina para a infraestrutura on-premises do SCCM.

    Arquitetura definida (FUTURA)

    Fluxo de implantação:

    Registro de Dispositivos:

    • Importação de Dispositivos: Importar a lista de dispositivos para o Microsoft Endpoint Manager (Intune).

    • Atribuição de Perfis: Atribuir perfis do Autopilot aos dispositivos importados.

    Provisionamento e Configuração:

    • Inicialização do Dispositivo: O usuário liga o dispositivo pela primeira vez e se conecta à internet.

    • Autenticação: O usuário é autenticado usando suas credenciais do Azure AD.

    • Aplicação de Perfis: O dispositivo recebe e aplica automaticamente o perfil de configuração atribuído.

    • Instalação de Aplicativos: Aplicativos corporativos são instalados e configurados.

    Monitoramento e Suporte:

    • Monitoramento Contínuo: Utilizar o Microsoft Endpoint Manager para monitorar o status e a conformidade dos dispositivos.

    • Suporte Remoto: Prover suporte remoto para resolução de problemas e manutenção dos dispositivos.

    Considerações de Segurança:

    • Políticas de Segurança: Implementar políticas de segurança rigorosas através do Microsoft Endpoint Manager.

    • Proteção de Dados: Assegurar a proteção de dados corporativos utilizando tecnologias de criptografia e controle de acesso.

    • Auditoria e Relatórios: Realizar auditorias regulares e gerar relatórios de conformidade e segurança.
