1.1 Estabelecer regras de gestão, acesso, manutenção e inclusão dos dados compartilhados.

2.1 Disponível em http://dados.caixa/portal/glossario?norma=TE109. 
3  
REGRAS 
3.1  
SOBRE A UTILIZAÇÃO 
3.1.1 Os novos sistemas devem utilizar as informações compartilhadas relacionadas no Anexo III - Áreas de 
interesse do modelo de dados compartilhado sempre que delas necessitem, ficando vetadas as soluções 
proprietárias, salvo aprovação prévia da SUART. 
3.1.2 Nenhum sistema possui autorização para alterar o conteúdo da base compartilhada de dados, exceto os 
designados na coluna “forma de atualização” do Anexo III - Áreas de interesse do modelo de dados compartilhado. 
3.1.3 Os sistemas desenvolvidos externamente ou os pacotes adquiridos são analisados pelos segmentos de 
administração de dados e informações quanto à integração com a base compartilhada de dados, caso necessitem 
utilizar objetos compartilhados. 
3.1.4 Os dados existentes nas áreas de interesse relacionadas no Anexo III - Áreas de interesse do modelo de dados 
compartilhado são de livre utilização por qualquer sistema da CAIXA, respeitados os graus de confidencialidade 
contidos no Anexo VI - Classificação das informações. 
3.1.4.1 O compartilhamento dos dados constantes no Anexo V - Tipos de entidade que necessitam de prévia 
autorização do gestor da informação para compartilhamento necessita de autorização dos respectivos gestores 
operacionais. 
3.1.5 É autorizada a replicação dos dados relacionados no Anexo III - Áreas de interesse do modelo de dados 
compartilhado (considerando as exceções do Anexo V - Tipos de entidade que necessitam de prévia autorização do 
gestor da informação para compartilhamento) para os demais ambientes não produtivos (HMP, TQS, DES), conforme 
grau de sigilo apresentado no Anexo VI - Classificação das informações.  
3.1.5.1 Somente as tabelas de uma área de interesse cujo grau de sigilo seja #PÚBLICO ou #INTERNO.TODOS podem 
ser replicados integralmente. As demais tabelas a serem replicados devem ser descaracterizados. 
3.1.6 É excepcionado o acesso ao modelo de dados físico das informações compartilhadas, sendo classificado o grau 
de sigilo de “#INTERNO.CONFIDENCIAL” para “#INTERNO.TODOS” conforme o [MN, OR016]. 
3.2  
ESTRUTURA 
3.2.1 O modelo de dados compartilhado é subdividido em áreas de interesse e cada uma delas possui gestores 
operacional e de informação conforme Anexo III - Áreas de interesse do modelo de dados compartilhado. 
3.2.1.1 O gestor operacional e o gestor da informação podem ser a mesma unidade. 
3.3  
CUSTO DAS MANUTENÇÕES DAS INFORMAÇOES DOS SISTEMAS COMPARTILHADOS 
3.3.1 O gestor da informação negocia e define o custeio das manutenções da base compartilhada e da camada de 
apresentação de aplicativos on-line que decorrerem de alteração em regras de negócio emanadas por instâncias 
internas ou externas à CAIXA. 
3.3.2 O gestor operacional custeia as manutenções na camada de apresentação de aplicativos “on-line” da base 
compartilhada por ele demandadas. 
3.3.3 Os gestores de sistemas clientes da base compartilhada de dados custeiam as manutenções necessárias para: 
▪ Adequação dos sistemas compartilhados em sua estrutura ou suas aplicações, para atender às necessidades dos 
seus sistemas, decorrentes de demandas internas ou de demandas legais originadas em órgãos ou instituições 
externas à CAIXA; 
▪ Adequações necessárias para a adaptação de seus sistemas. 
3.3.4 A VITEC custeia as manutenções dos sistemas compartilhados para adequações de solicitações de 
infraestrutura.

3.4  
RESPONSABILIDADES 
3.4.1  
SUART 
3.4.1.1 Gerir os modelos compartilhados em conformidade com os processos definidos. 
3.4.1.2 Orientar os segmentos de administração de dados e informações na condução de soluções para novos 
projetos e/ou sistemas legados na utilização da base compartilhada de dados. 
3.4.1.3 Decidir sobre a inclusão ou modificação de informações no modelo de dados compartilhado. 
3.4.1.4 Decidir sobre as solicitações de adoção excepcional de soluções proprietárias, com base no parecer técnico 
da Administração de Dados. 
3.4.1.5 Deliberar sobre estratégias de implementação de demanda de compartilhamento.  
3.4.1.6 Aprovar ou rejeitar proposta de solução de compartilhamento. 
3.4.1.7 Promover auditoria do conteúdo do modelo de dados compartilhado quanto à aderência às normas 
estabelecidas. 
3.4.1.8 Coordenar o processo de definição de estratégia de implementação. 
3.4.1.9 Estabelecer políticas, diretrizes e arquitetura relativas à replicação de dados das bases corporativas. 
3.4.2  
GEPTI 
3.4.2.1 Estabelecer políticas, diretrizes e implantar e operacionalizar as arquiteturas definidas pela SUART relativas 
à replicação de dados. 
3.4.3  
GEPAC/SUDEA/SUDEB 
3.4.3.1 Garantir o desenvolvimento e a manutenção dos objetos quando solicitada através de demanda cadastrada 
no SIGID. 
3.4.3.2 Garantir a aderência aos processos definidos na gestão do compartilhado.  
3.4.4  
CEPIP 
3.4.4.1 Garantir a disponibilidade dos dados, a segurança, a manutenção e a replicação das bases de dados 
compartilhadas entre os SGBD em produção. 
3.4.5  
SUDEA E SUDEB 
3.4.5.1 Representar a área de tecnologia junto às unidades envolvidas na origem, operacionalização e utilização das 
informações compartilhadas. 
3.4.5.2 Administrar os sistemas compartilhados, mantendo a padronização de todas as áreas de interesse das bases 
de dados compartilhadas. 
3.4.5.3 Coordenar e formalizar o acordo de serviço entre a área de tecnologia e os demais envolvidos com a definição 
e manutenção da base compartilhada de dados. 
3.4.5.4 Negociar previamente com a SUART as alterações na estrutura das informações a serem atualizadas.  
3.4.5.5 Apoiar o segmento de administração de dados e informações nos impactos decorrentes das atualizações na 
estrutura das informações compartilhadas. 
3.4.5.6 Coordenar, junto aos segmentos de administração de dados e informações e equipes de desenvolvimento de 
sistemas a correção de erros na atualização e/ou conteúdo da base compartilhada de dados. 
3.4.5.7 Levantar nos sistemas clientes das bases compartilhadas de dados, os impactos negociais ocasionados por 
atualizações na estrutura de informação. 
3.4.5.8 Demandar ações para atender política de compartilhamento. 
3.4.6  
ADMINISTRAÇÃO DE DADOS E INFORMAÇÕES 
3.4.6.1 Efetuar a validação de criação, alteração ou exclusão de objetos físicos no modelo de dados compartilhado 
em conformidade com o documento de proposta consolidada de solução de compartilhamento, conforme definido na 
[MN, TE074].

3.4.7  
GESTOR DA INFORMAÇÃO 
3.4.7.1 Garantir veracidade e atualidade do conteúdo dos dados da área de interesse da base compartilhada de dados 
sob sua responsabilidade, observando as diretrizes estabelecidas no [MN, PO007]. 
3.4.7.2 Enviar ao gestor operacional todas as informações necessárias para a atualização da base compartilhada de 
dados. 
3.4.7.3 No caso de erro nas informações enviadas por entidades externas à CAIXA, efetuar contato com os emissores 
e comunicar as unidades internas. 
3.4.7.4 Classificar as Informações de acordo com o [MN, OR016], mantendo atualizado o grau de sigilo dos dados no 
Anexo VI - Classificação das informações. 
3.4.8  
GESTOR OPERACIONAL 
3.4.8.1 Garantir a execução da atualização dos dados da área de interesse da base compartilhada de dados sob sua 
responsabilidade, observando as diretrizes estabelecidas no [MN, PO007]. 
3.4.8.2 Definir procedimentos internos ou externos à CAIXA, para atualização dos dados e regras de segurança da 
base compartilhada. 
3.4.8.3 Divulgar eventuais ocorrências de erro no que tange ao conteúdo da base compartilhada de dados ao gestor 
da informação responsável pelo atendimento à Unidade. 
3.4.8.4 Atuar para solução de inconsistências e melhoria da qualidade dos dados persistidos nas bases 
compartilhadas sob sua responsabilidade. 
3.4.8.5 Centralizar as informações provindas do gestor da informação.  
3.4.8.6 Responder no prazo de sete dias úteis às solicitações de utilização ou de alteração na área de interesse da 
base compartilhada de dados sob sua gestão.  
4  
PROCEDIMENTOS 
4.1  
UTILIZAÇÃO DOS DADOS DA BASE COMPARTILHADA DE DADOS 
4.1.1 A equipe de desenvolvimento de sistemas ou segmento de administração de dados e informações identifica a 
necessidade de utilização da base compartilhada por qualquer projeto em análise.  
4.1.2 Caso as informações necessárias constem do Anexo V - Tipos de entidade que necessitam de prévia 
autorização do gestor da informação para compartilhamento, a equipe de desenvolvimento de sistemas prepara 
documento com a relação das informações necessárias e encaminha à SUDEA e SUDEB para negociação junto ao 
gestor operacional. 
4.1.3 As demais áreas de interesse, Anexo III - Áreas de interesse do modelo de dados compartilhado, podem ser 
utilizadas conforme as orientações do segmento de administração de dados e informações.

4.2.1 Para inclusão de novas informações no modelo de dados compartilhado deve-se obedecer aos seguintes 
requisitos: 
4.2.1.1 Utilização da informação por mais de uma área de negócio 
4.2.1.2 Conformidade com os padrões e normas da administração de dados e informações. 
4.2.1.3 Existência de documentação e descrição clara das regras de negócio que envolve o assunto. 
4.2.1.4 Estabilidade do modelo de dados. 
4.2.1.5 Prévia identificação e comprometimento do gestor operacional e gestor da informação com a atualização da 
base compartilhada de dados, formalizada através de acordo de serviço. 
4.2.1.6 Atender aos requisitos básicos definidos no [MN, TE074]. 
4.3  
ALTERAÇÃO DO MODELO DE DADOS COMPARTILHADO E BASE COMPARTILHADA DE DADOS 
4.3.1 As alterações no modelo de dados compartilhado e base compartilhada de dados obedecem ao fluxograma 
constante do Anexo II - Fluxo da gestão dos modelos compartilhados.  
4.3.2 As alterações nos aplicativos do SIICO – telas, janelas, páginas ou programas de carga – obedecem ao 
fluxograma constante no Anexo II - Fluxo da gestão dos modelos compartilhados.  
4.4  
ATUALIZAÇÃO DO CONTEÚDO DA BASE COMPARTILHADA DE DADOS 
4.4.1 A atualização do conteúdo da base compartilhada de dados ocorre através dos aplicativos e arquivos constantes 
na coluna “forma de atualização” do Anexo III - Áreas de interesse do modelo de dados compartilhado. 
4.4.2 As unidades de origem da informação, quando forem diferentes do gestor operacional, encaminham as 
informações ao gestor operacional, para atualização da base compartilhada de dados.  
4.4.2.1 Os gestores operacionais, através de seus representantes efetuam as atualizações na base compartilhada de 
dados. 
4.4.3 Toda carga para atualização de conteúdo tem que obedecer às regras de integridade definidas para o banco de 
dados. 
4.4.4 Qualquer exceção será negociada e autorizada pela SUART. 
4.5  
UTILIZAÇÃO E ACESSO DA BASE COMPARTILHADA DE DADOS 
4.5.1 Para acesso à base de dados compartilhada, o SIICO deverá disponibilizar API. 
4.5.2 Os sistemas consumidores deverão postar suas solicitações por meio de APIs providas pelo Gerenciador de 
APIs. 
4.5.3 A construção e disponibilização de novas APIs deverão ser aprovadas pela SUART. 
4.5.4 Os sistemas que já possuem integração com o SIICO com a utilização de views ou componentes devem avaliar 
junto ao segmento de Administração de Dados e Informações a possibilidade de adequação à arquitetura descrita 
acima. 
4.6  
ADOÇÃO EXCEPCIONAL DE SOLUÇÕES PROPRIETÁRIAS 
4.6.1 Para a adoção de soluções proprietárias (não utilização da base compartilhada de dados) o segmento de 
Administração de Dados e Informações encaminha para a SUART solicitação acompanhada de relatório onde conste:  
▪ Parecer favorável do segmento de Administração de Dados e Informações; 
▪ Razões que inviabilizem o compartilhamento de dados; 
▪ Detalhamento das propostas da equipe de desenvolvimento de sistemas, incluindo modelo de dados e conceituação 
das entidades; 
▪ Plano de migração para a base compartilhada quando a solução for temporária.
