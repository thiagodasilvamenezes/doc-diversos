3 Operacional Passo a Passo 
3.1 Definição de Parâmetros para a utilização 
1º 
Utiliza as informações compartilhadas em novos sistemas, 
vetadas as soluções proprietárias 
2º 
Altera o conteúdo da base compartilhada de dados somente os 
designados na coluna “forma de atualização” 
3º 
Analisa os sistemas desenvolvidos externamente ou os pacotes 
adquiridos quanto à integração com a base compartilhada de 
dados 
4º 
Define a utilização por qualquer sistema da CAIXA, respeitados 
os graus de confidencialidade 
4º 
Define os requisitos para inclusão de novas informações no 
modelo de dados compartilhado 
3.2 Estabelecimento de Responsáveis pelos Custos de Manutenção 
1º 
Negocia e define pelo gestor da informação o custeio das 
manutenções 
2º 
Custeia pelo gestor operacional as manutenções na camada de 
apresentação de aplicativos  
3º 
Custeiam pelos gestores de sistemas clientes as manutenções 
necessárias 
4º 
Custeia pela VITEC as manutenções dos sistemas compartilhados 
para adequações de solicitações de infraestrutura 
3.3 Definição de Acessos para a utilização 
1º 
Utiliza API para acesso à base de dados compartilhada 
2º 
Avalia e aprova a construção e disponibilização de novas APIs 
3º 
Avalia adequação à arquitetura CAIXA das integrações com o 
SIICO com a utilização de views ou componentes 
4º 
Solicita a SUART a adoção de soluções proprietárias
