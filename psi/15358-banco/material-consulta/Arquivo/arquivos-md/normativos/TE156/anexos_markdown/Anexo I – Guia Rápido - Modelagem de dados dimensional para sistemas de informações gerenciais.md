## GUIA RÁPIDO: MODELAGEM DE DADOS DIMENSIONAL GERENCIAIS #INTERNO.TODOS
## TE 156
1 Resumo
Definir as regras de modelagem de dados dimensional para validação dos
modelos de dados dos sistemas de informações gerenciais.
Público: SUDEA, SUDEB, CESOA, CESOB.
2 Exigências/Links
2.1 Acesso aos sistemas
Registro de demandas de sistemas: Incluir o link GID
Registro de Insumos da demanda e da entrega do Laudo de Validação:
http://gestaodedados.coresp.caixa/#
2.2 Normativos/MO
TE156 Modelagem de dados dimensional para sistemas de informações
gerenciais
3 Operacional Passo a Passo
3.1 Avaliar demandas que caracterizem SIG
1º
Efetua o levantamento dos requisitos da demanda
2º
Define a forma de integração entre os requisitos das diversas
áreas
3º
Efetua o Acordo de Nível de Serviço entre as áreas envolvidas
3.2 Validar modelo de dados dimensional
1º
Garante a reusabilidade e compartilhamento de soluções
2º
Garante que os modelos de dados estejam aderentes aos
padrões e aos requisitos negociais
3º
Cadastra no Glossário de Termos os termos a serem utilizados
4º
Consulta ABD quanto a validação de objetos físicos
5º
Elabora Laudo de Validação com parecer sobre os objetos
avaliados
3.3 Implementar demandas de SIG
1º
Garante que o modelo de dados analisado atenda de forma
adequada os requisitos de desempenho
2º
Insere e/ou atualiza no modelo de dados qualquer propriedade
física alterada nos scripts
3º
Gera o script DDL para implementação
4º
Efetua a gestão de versionamento dos scripts na ferramenta
