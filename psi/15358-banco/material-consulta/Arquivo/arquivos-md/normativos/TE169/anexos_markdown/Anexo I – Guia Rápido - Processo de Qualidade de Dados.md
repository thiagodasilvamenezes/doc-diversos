## TE169 – PROCESSO DE QUALIFICAÇÃO DE DADOS
3 Operacional Passo a Passo
3.1 Solicita diagnóstico da Qualidade dos Dados
1º
Define metas de qualidade e regras negociais para os dados
2º
Homologa os resultados do diagnóstico
3º
Identifica ações preventivas e corretivas nos aplicativos dos
sistemas
4º
Define Planos de Qualidade para melhorias
5º
Define a periodicidade e indicadores de monitoramento da
qualidade
3.2 Prepara ambiente para execução do diagnóstico da Qualidade
1º
Disponibiliza a infraestrutura de ambiente relacionados à
ferramenta
2º
Cria as estruturas de banco de dados de forma persistente
3º
Elabora e executa roteiros para extração de amostra de dados
4º
Define o processo para concessão de acesso logico
5º
Desenvolve os Planos de Diagnóstico e de Melhoria de
Qualidade
6º
Presta suporte nos ajustes de integração ao ambiente CAIXA
3.3 Realiza diagnóstico da Qualidade dos Dados
1º
Define com o gestor da informação as regras para geração de
amostras de dados
2º
Executa Diagnóstico de Qualidade de Dados
3º
Com base nos Planos de Qualidade, elabora Plano de Execução
para o ambiente de produção
4º
Executa o monitoramento da qualidade com base na definição
da periodicidade e indicadores aprovados
