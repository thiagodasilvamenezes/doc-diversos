<div class="anchor-h3">

### Histórico<span class="a_6XoDB_A4j40"></span>

<a href="https://caixa.sharepoint.com/sites/NPRD/SitePages/ADI-ComeceAqui-Fundamentos.aspx#hist%C3%B3rico" class="a_6XoDB_A4j40 f_5euva_A4j40 focusBorder-183" role="link" data-sp-anchor-id="histórico" target="_self" style="left: 124px; top: 39.5px;" title="Permalink para Histórico"><em></em></a>

</div>

Inicialmente, os sistemas de bases de dados eram coleções de arquivos manipulados por programas específicos. Esses sistemas não ofereciam mecanismos adequados para controle de acesso simultâneo, o que dificultava a integridade, a consistência dos dados, problemas como redundância, inconsistência de informações e dificuldade na manutenção dos dados.

\
A partir dessa necessidade, foram criados os SGBDs (Sistemas Gerenciadores de Banco de Dados), que fazem o controle de acesso, de redundância, recuperação de falhas, entre outros. Exemplos de SGBDs são: Oracle, SQL Server, DB2, PostgreSQL, MySQL, Access.

**SBD** (Sistema de Banco de Dados) = significado conceitual amplo, contém todos os recursos necessários para gerenciar o BD (BD + SGBD + aplicações + usuários + regras de negócio). Ou seja, tudo que envolve o uso e funcionamento do banco de dados.

 

 

**SGBD** (Sistema Gerenciador de Banco de Dados) = software capaz de manipular as informações do banco de dados e interagir com o usuário.

\*RDBMS = Relational Database Management System = SGBD Relacional

 

 

**BD** (Banco de Dados) = dados + metadados. É um conjunto organizado de dados que podem ser acessados, gerenciados e atualizados.
